# PulseWatch frontend

Next.js UI pre PulseWatch. Setup, screenshoty a celý stack sú v [README v koreni repozitára](../README.md).

```bash
cp .env.example .env.local
npm install
npm run dev
```

Appka beží na [http://localhost:3000](http://localhost:3000). GraphQL API musí bežať na `:4000`.

```bash
npm test
npm run lint
```
